# 2026-10-20

## Proyecto PolyMusic (ASP Clasico + SQL Server) — construccion completa

Se desarrollo la aplicacion web tipo Spotify "PolyMusic" segun `PROMPT_PolyMusic.txt`,
usando ASP Clasico (VBScript) sobre IIS y SQL Server (BDD_PoliMusic ya provista en `BDD_PoliMusic.sql`).

### Arquitectura de archivos creada
- `login.asp`, `home.asp`, `logout.asp`
- `css/style.css` (tema morado + blanco degradado, responsive, player fijo)
- `js/player.js` (reproductor tipo Spotify, busqueda, atajos, sessionStorage)
- `includes/cnx.asp` (ADODB / SQLOLEDB, con pagina de error amigable)
- `includes/helpers.asp` (H, SqlS, rutas de recursos, roles, flash, catalogos, OpenRS)
- `includes/header.asp` / `includes/footer.asp` (layout + barra de reproduccion)
- `includes/playlist_lib.asp` (CRUD de playlists compartido admin/usuario)
- `admin/songs.asp`, `artists.asp`, `albums.asp`, `users.asp`, `playlists.asp`
- `user/playlists.asp`
- `ajax/play.asp` (incremento de PLAYS en JSON)

### Decisiones tecnicas importantes
- **ADO**: todas las consultas de lectura usan `OpenRS()` con `CursorLocation = adUseClient`
  (cursor estatico). Motivo: SQLOLEDB no soporta MARS, y home.asp/admin abren varios
  recordsets simultaneos; con `oCnx.Execute` fallaba con "Connection is busy".
- **Login**: valida contrasena en texto plano **o** SHA1 usando `HASHBYTES('SHA1', ...)` en SQL,
  evitando implementar SHA1 en VBScript.
- **Rutas de recursos**: el seed guarda `~/songFiles/x.mp3`; se normaliza con `FileBaseName`
  y se resuelve contra `SongFilesAndImages_resources/*`, verificando existencia con FSO.
  Si el mp3 no existe se usa `bensound-adventure.mp3`; si falta la imagen se dibuja
  un placeholder morado con la inicial (clase `.art`).
- **Codificacion**: directiva `CodePage="65001"` + `Response.CharSet="utf-8"` en cada pagina.
- **Sesion**: `Session("ID_USER")`, `USERNAME`, `USER_TYPE`, `USER_PHOTO`.
  `RequireLogin` / `RequireAdmin` (con `DenyAccess` estilizado) al inicio de cada pagina.
- **Uploads**: se opto por seleccion de archivos existentes (`<datalist>` generado con FSO)
  en lugar de parser multipart en VBScript.

### Verificacion
- Balance de bloques ASP/If/Do/For/Sub validado con script.
- Diseno verificado con capturas de Playwright (login, home, CRUD) en escritorio y movil.
